# Design Direction

The website should NOT look like a traditional church website.

Instead, it should resemble a premium SaaS landing page with subtle ministry aesthetics.

Overall Mood

- Elegant
- Luxurious
- Modern
- Peaceful
- Spirit-filled
- Inspiring
- Minimal
- Professional

Every section should have breathing space.

Avoid visual clutter.

Use generous padding throughout.

# Motion Design

Every interaction should feel alive.

Use Framer Motion extensively.

Animations include

- Fade In
- Slide Up
- Scale
- Blur Reveal
- Stagger Children
- Floating Objects
- Hero Text Reveal
- Card Hover Lift
- Magnetic Buttons
- Smooth Page Transition
- Animated Counters
- Scroll-triggered Animations
- Image Parallax

Animation Duration

0.3–0.8 seconds

Ease

easeOut

Never make animations distracting.
